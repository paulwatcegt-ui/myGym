03 / BUILT ON OPENGYM

继承基础，打磨自己的习惯。

对比 openGym 1.4.1 与 myGym v1.0.0。
明确区分原有能力与二次开发的改动。

openGym → myGym

计划、记录、备份、同步和多数统计能力来自原版。myGym 聚焦动作整理、中文资料和日常操作，不将上游能力作为自研新增功能。

改动范围openGym 原版myGym 的实际变化
新增动作库个人管理支持自建动作与临时筛选增加内置动作编辑、隐藏与恢复；保存筛选范围、调整标签顺序。
扩充中文动作资料已有部分中文训练要领为 5632 个内置动作补齐中文简介与要领；新增机器译文仍需逐条校对。
调整时长与统计展示摘要显示连续周数改为累计训练时长，仅计算有有效起止时间的已完成训练；动作进度卡片前移。
新增进度照片操作保留原有照片时间线查看器增加删除与替换；替换保留训练归属和其他附件。
移除器械管理入口可管理器械场景、杠铃片和哑铃库存移除这些管理界面；旧配置仍可能影响筛选和重量选择。
调整Android 更新原版应用内更新流程关闭应用内更新，后续获取正式 APK 手动覆盖安装。

ANDROID / 安装与手动更新

  1. 先备份

    从现有版本导出备份；包含照片或视频时，选择含媒体 ZIP。

  2. 获取正式安装包

    公开下载开放后，核对版本和 SHA-256，再在 Android 上打开 APK，按系统提示允许该来源安装。

  3. 导入并核对

    测试版与正式版数据隔离，首次需导入备份。确认训练、计划和照片齐全后再处理旧版本。

  4. 后续覆盖安装

    沿用相同包名与签名，备份后安装新版，不先卸载正式版；应用内自动更新已关闭。
