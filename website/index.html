03 / BUILT ON OPENGYM

继承基础，打磨自己的习惯。

基于 openGym 1.4.1，对比涵盖 myGym v1.0.0 与 v1.1.0 已发布改动。
明确区分原有能力与二次开发的改动。

openGym → myGym

计划、记录、备份、同步、多数统计及教练基础能力来自原版。myGym 在此基础上改进动作整理、中文体验与教练个性化；下表区分基础调整和 v1.1.0 更新。

改动范围openGym 原版myGym 的实际变化
v1.1.0教练交互沿用上游教练和计划能力默认进入训练问答，需要修改计划时再选择“调整计划”；计划须确认后才应用。
v1.1.0可控长期记忆沿用原有问卷与训练上下文可手动保存、编辑或清空长期训练备注；聊天不会自动写入长期记忆。记忆随咨询发送给所选供应商。
v1.1.0教练动作偏好保留原有器械与历史动作筛选基础可搜索并设置偏好、避开动作；普通候选排除避开或隐藏项，相关历史动作仅作分析上下文。结构化计划会校验明确避开的动作。
v1.1.0供应商配置沿用原有教练供应商机制新增 DeepSeek、Kimi、智谱 GLM、MiniMax、星火、混元及豆包配置入口，需自行配置有效账户、密钥和模型；未逐一验证在线调用。
v1.1.0中文与更新入口保留已有用户语言偏好与手动安装方式首次安装默认简体中文；教练动作名使用中文或个人改名，保留英文名称偏好。应用内“前往官网检查更新”直达版本页。
新增动作库个人管理支持自建动作与临时筛选增加内置动作编辑、隐藏与恢复；保存筛选范围、调整标签顺序。
扩充中文动作资料已有部分中文训练要领为 5632 个内置动作补齐中文简介与要领；新增机器译文仍需逐条校对。
调整时长与统计展示摘要显示连续周数改为累计训练时长，仅计算有有效起止时间的已完成训练；动作进度卡片前移。
新增进度照片操作保留原有照片时间线查看器增加删除与替换；替换保留训练归属和其他附件。
移除器械管理入口可管理器械场景、杠铃片和哑铃库存移除这些管理界面；旧配置仍可能影响筛选和重量选择。
调整Android 更新原版应用内更新流程关闭应用内更新，后续获取正式 APK 手动覆盖安装。

v1.0.0 的动作库、中文资料、统计与照片改动继续保留。v1.1.0 使用教练需自行配置供应商；服务器配对模式需同步更新后端。请勿在教练记忆中填写密码或 API 密钥；清空记忆不会删除先前聊天或供应商记录。实际覆盖安装与个人数据保留仍需真机验收。

04 / THE STORY

从个人需要出发，
在每一次使用中改进。

一个开源项目，也是一件长期使用的工具。
让真实的训练习惯，决定下一步改什么。

01

发现需要

训练的基础能力已经很完整，但动作整理、中文阅读与训练摘要，还可以更贴近日常习惯。

02

基于 openGym 开发

复用原项目的训练与数据体系，调整品牌，增加动作管理和筛选偏好，补齐中文资料。

03

在使用中打磨

改进累计时长、统计信息位置与照片操作；围绕数据保留、同步和备份进行回归检查。

04

持续完善

继续校对中文术语、验证正式版迁移和覆盖升级，完善旧器械配置的维护方式。
