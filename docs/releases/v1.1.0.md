# myGym v1.1.0

Android 正式版，版本代码 28。基于 openGym 二次开发，原项目版权、许可证与第三方素材声明继续保留。

## 新增功能

- **独立训练问答**：教练默认先回答问题；需要调整训练安排时，选择“调整计划”。提问不会直接应用计划，也不会清空待确认提案。
- **可编辑的教练记忆**：在教练的“更多 → 教练记忆”保存长期训练备注，后续咨询会参考这些内容。可以随时查看、修改或清空，聊天不会自动改写长期记忆。
- **动作偏好**：按中文、英文名称或动作 ID 搜索，设置偏好与希望避开的动作，辅助教练选择候选。
- **更多 AI 供应商选项**：加入 DeepSeek、Kimi、智谱 GLM、MiniMax、讯飞星火、腾讯混元及豆包的配置入口。使用前需自行配置对应账户、密钥和模型；模型可用性、费用与调用限制由供应商决定。

## 调整与修复

- 教练动作卡片与发送给模型的动作上下文支持中文和个人改名，保留动作 ID 与原名，原有英文名称偏好继续生效。
- 候选选择结合器械、明确偏好及已练动作；避开或隐藏的动作不进入普通候选。历史训练中的相关动作仍保留为分析上下文。
- 新计划及审查中新增、替换动作时，明确避开的动作会触发输出校验，最多尝试一次修复。
- 首次安装默认使用简体中文；已有用户的语言设置保持不变。
- 浏览器预览与安装版共用“关于与更新”内容，增加“前往官网检查更新”，直接进入官网版本下载页。下载安装仍由用户手动完成。

## 更新须知

- 安装或更新前请先导出备份；含照片和视频时选择包含媒体的 ZIP。
- 沿用正式版包名和固定签名；从 1.0.0 更新时直接打开新版 APK 覆盖安装，不要先卸载旧版。
- 本次没有主动迁移或删除训练记录的数据格式；教练个人资料新增可选记忆与动作偏好字段。旧资料缺少这些字段时按空值读取。降级后的新字段保留情况未验证，不建议随意降级。
- 记忆随个人资料保存、备份和配对同步，并在咨询时发给所选 AI 供应商。请勿填写密码或 API 密钥。清空影响后续请求，不会删除此前聊天或供应商已接收的内容。
- 自带密钥模式使用本地新教练流程；服务器配对模式需要后端同时更新。单纯部署静态网站不提供配对、账户或同步后端。
- 测试包与正式包数据隔离；从测试包迁移时应导出、导入并核对数据。

## 验证范围

相关前端回归 348 项通过；教练核心与服务端相关回归 126 项通过。浏览器使用模拟供应商响应验证记忆保存、刷新、清空、问答与未决提案保留；这些检查不代表已验证真实模型回答质量或所有供应商的在线可用性。

签名 APK 的编译、Android lint、证书及包名版本校验结果随本地构建保存。当前没有连接真机，尚未进行 1.0.0 → 1.1.0 的实际覆盖安装及个人数据保留验收。

官网首页、版本与下载页展示正式发布记录；尚未发布的内容单列为“开发中”。下载地址和文件校验值以对应 GitHub Release 附件为准。
